# سیستم طراحی نونگاران (Nonegaran Design System)

## فلسفه‌ی طراحی

نام «نونگاران» از «نون» (نان) می‌آید — نان‌پزها. این پروژه این استعاره را
مبنای هویت بصری قرار داده: کتاب به‌عنوان خوراک روزانه‌ی ذهن. به همین دلیل
پالت رنگی و تایپوگرافی، به‌جای الگوهای رایج سایت‌های AI-generated (کرمِ
مایل‌به‌صورتی + سریف کنتراست‌بالا + لعاب ترکتال #D97757)، حول محور
«گندم و جوهر» طراحی شده است.

## رنگ (Color Tokens)

توکن‌ها در `frontend/src/app/globals.css` تعریف شده‌اند.

| Token | Hex | نقش |
|---|---|---|
| `--color-paper` | `#EAE0C4` | پس‌زمینه‌ی اصلی (Light) |
| `--color-ink` | `#1B1A17` | متن اصلی / پس‌زمینه‌ی Dark |
| `--color-saffron` | `#B8860B` | تاکید اصلی — CTA |
| `--color-petrol` | `#1F4A46` | تاکید ثانویه — لینک‌ها |
| `--color-clay` | `#8C3B2E` | خطا (مصرف محدود) |
| `--color-moss` | `#3F5E3A` | موفقیت (مصرف محدود) |

Dark mode با `[data-theme="dark"]` روی تگ `<html>` فعال می‌شود
(کنترل‌شده توسط `ThemeToggle.tsx`، ذخیره در `localStorage`).

## تایپوگرافی

- **Display**: Noto Naskh Arabic — عنوان‌ها، Hero، نام کتاب‌ها.
- **Body/UI**: Vazirmatn — متن رابط کاربری و بدنه‌ی متن.

هر دو فونت به‌صورت **Self-hosted** در `frontend/src/fonts/` قرار دارند
(نه از طریق Google Fonts) — دلیل فنی در README آمده است.

## چیدمان و اصول

- بدون Card-grid یکنواخت؛ Grid نامتقارن بر اساس اهمیت کتاب.
- شعاع گوشه (Border-radius) فقط برای کنترل‌های کوچک UI، نه برای سطوح بزرگ.
- یک Motion محسوس در هر صفحه، نه انیمیشن روی هر عنصر.
- `prefers-reduced-motion` رعایت می‌شود.
- فوکوس صفحه‌کلید همیشه قابل‌مشاهده است (`:focus-visible`).
